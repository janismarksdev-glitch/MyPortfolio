# Janis Marks Portfolio — Next.js

Built with Next.js App Router, React, and TypeScript.

## Start locally
```bash
npm install
npm run dev
```
Visit http://localhost:3000.

## Customize
- Replace `YOUR_EMAIL@example.com` in `app/page.tsx` with your actual email.
- The five project cards and technology stacks are based on the resume.
- Project screenshot assets are stored in `public/projects/`.
- Edit `app/page.tsx` to update profile, project descriptions, skills, or links.

## Deploy
Push this project to GitHub, then import it into Vercel.


## Visual refresh
